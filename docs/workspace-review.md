# 工作区第二版审阅说明

入口 `/workspace/`，原 `/workspace/index.html` 自动跳转。此版本未推送或部署线上。

## 已实现的流程

- 今天：快速记录到待安排、今日与近期任务、逾期重新安排、搁置与恢复；任务支持待安排、单日、连续区间和重复规则（每天、工作日、每周、每月、自定义间隔），区间/重复任务按日期分别完成。
- 日历：单击查看当天任务/日程/日记；独立区间选择模式支持跨月建目标。
- 目标：进行中、暂停、完成、取消；调整先预览，第二次确认后保存；已完成任务日期保留；超出目标范围提示；下一步任务。
- 项目：任务、目标、日程、文档聚合；归档后从日常视图隐藏，恢复后重新显示。
- 删除：任务、目标、日程和笔记软删除至回收站；即时撤销最近操作；不提供永久清空入口。
- 日记：自动关联计划日期或实际完成日期当天的任务；自由正文、可选模板；选择正文转任务并保留来源链接。
- 日程：开始/结束时间、每日/每周重复、重复截止日期、单次取消、整组修改、时间冲突提示。按本机时区，不支持跨午夜。
- 文档：Markdown 编辑和净化预览；本地 PNG/JPEG/WebP/GIF 图片（每张 2MB）；30 个历史版本与恢复；默认私密；屏蔽远程图片自动请求。
- 本机保存：IndexedDB、v1 旧草稿迁移、JSON 导入/导出、导入前恢复点、手动恢复点（最近 5 个）、保存失败提示、标签页并发保护。

## 云同步状态

按用户选择，云同步稍后配置。本次只提供未启用的可选适配代码和设置入口。没有恢复 Blue2199，也没有创建/修改远程数据库。真实注册、登录、跨设备同步和服务端 RLS 尚未执行联调，不能视为已上线。

准备好项目后，在正确的 Supabase 项目执行 `workspace-cloud-setup.sql`，检查 RLS 后，从工作区填写项目 URL 与 publishable key。前端不接收 service-role/secret key。不同项目/用户使用独立本机存储命名空间。本地草稿不会自动上传，可通过备份导入。

同步设计：版本号比较及原子条件写入，发现远程不同版本停止覆盖并提示选择；网络失败保留本地。退出登录回到独立本地空间。后续上线前须用两个真实测试账号验证跨账号隔离、并发版本冲突、离线重试与图片体积限制。

## 范围

保持简单排版，未增加多人协作、复杂表格、积分、AI 总结或公开分享。私密指不会发布到个人主页；本地模式不提供设备级加密，浏览器站点数据应定期备份。
